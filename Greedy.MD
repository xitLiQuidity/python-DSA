#greeDy algorithm 

it is a algorithmic technique to get the best optimal solution in each step without reconsidering the previous result 

steps:

- get the values either in ascending or descending order based on the scenario
ex - list of values, height of students, start and end time of a given tasks etc.

- start the iteration based on the given input value either it may be integers, list or String 

- consider highest or lowest value based on the scenario

- break the bigger problem into smaller sub problem and store the result into some location

- continue the steps until you get a final result



ex-
write a program to display the total number of coins or the denomination of coins by using the input and the list of coins.
